Privacy Policy

THINKLET Archive is a personal backup utility operated by and for a single individual, its owner.

  • Data accessed. The application requests the Google Drive scope drive.file, which only grants access to files and folders that the application itself creates. It cannot read, modify or delete any other content in the owner's Google Drive.
  • Data uploaded. The owner's own camera recordings and related metadata are uploaded from the owner's computer to the owner's Google Drive.
  • Storage and sharing. Data is stored only in the owner's Google Drive. It is not shared with, sold to or disclosed to any third party. No analytics or advertising services are involved.
  • Credentials. OAuth tokens are stored only on the owner's computer. No server operated by the application receives or stores any credential.
  • Deletion. The owner can delete any uploaded data at any time in Google Drive and can revoke the application's access at myaccount.google.com/permissions.

Google API Services usage complies with the Google API Services User Data Policy, including the Limited Use requirements.
